## Parte A: Plano de Testes Manuais (Azure Boards)

Os 13 casos de teste manuais, cobrindo as funcionalidades principais do sistema (Aplicativo Móvel e Extensão Web), foram planejados e documentados na plataforma Azure Boards.

#### **Observação sobre a Metodologia de Documentação**

Durante o desenvolvimento do projeto, foi identificado que a licença de usuário no Azure DevOps não concedia acesso à funcionalidade dedicada de **"Test Plans"**.

Para contornar esta limitação, foi adotada uma abordagem alternativa, criando cada caso de teste diretamente como um **"Work Item"** do tipo "Test Case". Esta metodologia foi previamente **discutida e validada com o professor**, que confirmou ser um caminho totalmente aceitável para a entrega do trabalho.

Dessa forma, toda a documentação exigida — incluindo objetivo, dados de entrada/saída, passos detalhados e critérios de aceite — está contida dentro de cada Work Item, cumprindo integralmente os requisitos do plano de testes manuais.
